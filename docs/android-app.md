# 拾序 Android 手机应用

版本 0.1.0，支持 Android 8.0 及以上。签名安装包：`release/android/shixu-0.1.0-android.apk`。这是使用系统 WebView 的独立应用，工作台从现有 HTTPS 服务加载，首次打开需要联网。

## 安装与同步

将 APK 发送到安卓手机，打开安装文件，按系统提示允许当前文件管理器或浏览器安装应用。安装后打开“拾序”，在“账号与多端同步”登录已有账号；新手机选择“打开账号工作区”，即可接收电脑上的记录。

服务地址为 `https://8.147.235.91`，无需配置域名或额外运行本机服务。已有账号登录不需要注册邀请码；只有新注册需要它。邀请码没有内置到 APK，当前邀请码保存在本机 `release/server-access.txt`。

手机应用、手机浏览器和电脑应用分别保存本机数据与登录状态，通过同一账号同步。主工作区与版面实验室分别同步。首次联网并完成页面缓存后，支持离线重新打开和记录，联网后继续同步；清除应用数据、卸载应用或清除缓存后，需先联网打开。卸载前请确认记录已同步或已导出。

## 手机适配

界面适配状态栏、底部手势区域与软键盘。系统返回键优先关闭工作台弹窗，然后返回上一页。JSON 导入调用系统文件选择器；导出调用系统“保存文件”对话框，可以自行选择保存位置。单次手机导出最多 64 MB，更大的恢复包请在电脑导出；普通 JSON 导入仍受工作台 5 MB 限制。

应用仅声明网络与网络状态权限，不申请相册、联系人、摄像头或整个存储空间权限。文件访问通过用户明确选择的系统文档入口完成。仅在受信任工作台建立备份传输通道；外部网页交给浏览器打开，不授予网页通用本机接口。证书验证失败时停止加载，不绕过 HTTPS 校验。发布包关闭 WebView 调试。

## 构建与更新

需要 JDK 17 或以上、Android SDK Platform 35 和对应构建工具。设置 `JAVA_HOME` 与 `ANDROID_HOME` 后，在项目根目录执行：

```powershell
npm run android:build
```

Gradle Wrapper 固定为 8.9，Android Gradle Plugin 为 8.7.3。首次构建会创建本机签名密钥，以后继续使用同一密钥。签名材料位于 `.signing/android/shixu-release.jks` 与 `.signing/android/keystore.properties`，已排除出版本管理与交付目录。请将这两个文件一起安全备份；失去原密钥将无法直接覆盖更新已安装应用。不要将私钥或密码文件发送给使用者。

前端更新由现有服务器与页面缓存更新机制提供。修改原生程序时，应递增 `android/app/build.gradle` 中的 `versionCode`，并用原签名重新构建。当前交付为直接安装的 APK，尚未发布到应用商店。

## 验证方式

`scripts/verify-android.mjs` 在独立 Android 测试模拟器中检查可信 HTTPS、手机与独立电脑浏览器同步、系统文件导出与导入、离线编辑及重连同步、系统返回键、重启保留登录与版面实验室。它只清除独立调试包 `app.shixu.workspace.debug` 的数据；不要在个人设备上运行这个测试脚本。发布包为 `app.shixu.workspace`，单独验证安装、启动与调试关闭。真机兼容性仍应以手机实际安装体验为准。
