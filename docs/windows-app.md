# 拾序 Windows 桌面版

版本 0.1.0，适用于 Windows 10 / 11 的 x64 电脑。安装包位于 `release/desktop/拾序_0.1.0_x64-setup.exe`，安装到当前用户，提供开始菜单入口和卸载程序。

## 使用

安装后直接打开“拾序”。桌面客户端默认连接 `https://8.147.235.91`，无需运行 Node 或本机预览服务。首次启动需要联网加载工作台；页面缓存完成后支持断网重新打开和本机编辑，联网后继续同步。

“我的项目”默认使用项目路线图，可在顶部切换到看板或表格，选择会留在本机。路线图显示主工作区已有的项目、任务和笔记；点击任务站点即可完成任务，右侧可保存项目笔记或逐行添加任务。桌面工作台更新后重新打开即可加载新布局。

点击“账号与多端同步”，使用已有账号登录。新设备选择“打开账号工作区”，即可接收该账号的记录；本机有需要加入账号的记录时选择“同步本机工作区”。主工作区与版面实验室仍分别同步。

注册邀请码仅用于控制新账号注册，登录不需要它。邀请码不内置在安装包中，当前服务的邀请码见本机 `release/server-access.txt`。你也可以继续用手机浏览器访问同一地址并登录相同账号。

桌面版有独立的登录会话和本机数据，不会直接读取 Edge/Chrome 或旧的 `127.0.0.1` 预览记录。旧本机记录应先导出 JSON，再到桌面版导入；已有云端记录直接登录即可。备份支持正常下载和导入。

## 运行与更新

使用 Tauri 2 和系统 WebView2，安装包内含微软 WebView2 引导安装器：系统缺少运行环境时，需要联网下载运行环境。桌面版工作台随服务器更新，无需每次重新安装；更换服务地址或升级原生程序时需要新安装包。

当前安装包未进行商业代码签名，Windows 会将发布者标为未知。它不包含邀请码、SSH 密钥、服务器密码或测试账号。

## 验证

使用发布模式程序及隔离的 WebView2 测试数据目录，已验证可信 HTTPS、桌面到独立 Edge 的同账号同步、JSON 导出、离线重新加载及编辑、重连同步、版面实验室，以及重启后保留登录与记录。

NSIS 中文安装器已在隔离目录完成安装检查。安装后的程序与普通运行文件仅有 Tauri 写入的安装类型标记不同。测试使用临时生成的 QA 账号，随后精确清理；测试标志和远程调试端口仅用于本机测试进程，不内置到交付程序。

开发构建：安装 Node.js 24、Rust stable、Visual Studio C++ Build Tools 后执行：

```powershell
npm ci
npm run desktop:build
```

输出位于 `src-tauri/target/release/bundle/nsis/`。Rust 依赖由 `src-tauri/Cargo.lock` 固定，npm 依赖由 `package-lock.json` 固定。打包实现遵循 [Tauri Windows 安装器文档](https://v2.tauri.app/distribute/windows-installer/)，远端工作台不被授予本机文件或命令执行权限。
