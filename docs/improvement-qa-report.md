# 首轮可靠性与性能改进

日期：2026-10-28，Asia/Shanghai。

## 已完成的改动

- 项目创建、属性添加、视图设置及项目／笔记关联只在保存成功后关闭表单。失败时回滚未提交的数据，保留表单选择和文字，支持释放空间后点击按钮或按 Ctrl/Command + S 重试。迁移失败、内容缺失和其他窗口更新仍会阻止写入。
- 主工作区增加 IndexedDB 正文存储，覆盖笔记、模板、项目说明和任务说明。单段超过 4,096 字符，或正文总量超过 128 Ki 字符时转存；短小工作区保留原有存储方式。内容提交成功后才生成引用；日常输入先同步保存文字副本，再后台转存，转存失败仍可刷新恢复文字。迁移、导入、同步和回收站恢复均先保存内容再提交引用。
- 同步 GET 支持 ETag／If-None-Match，未变化时返回空的 304。校验包含账号、主工作区／实验室、版本及模板兼容格式。服务端先只读取版本号，避免无变化时取出完整数据库正文。旧服务器返回完整响应时仍可同步。
- Android 按网页请求区分 JSON 导入与图片上传，支持图片多选及系统多选结果。
- 修复仅包含图片的文档全选后无法输入的问题，保留 CodeMirror 图片周围的可编辑光标位置。
- 更新离线缓存版本、存储说明、Android 导入限制及历史产品草案状态。

- `npm run test:unit`：90 项通过，含新增 ETag 的账号、空间、版本及客户端格式隔离测试。
- 原有同步浏览器测试：17 项通过。
- 新增条件读取与长正文跨设备恢复浏览器测试：1 项通过，验证 304 空响应、本机修改上传、另一设备接收长正文及刷新恢复。
- 三种屏幕尺寸的保存关联失败与重试测试：3 项通过。
- 三种屏幕尺寸的未保存说明导出恢复测试：3 项通过。
- 最终桌面／平板／手机回归：129 项全部通过，覆盖实时编辑器、图片、本机备份恢复、大正文、保存快捷键和保存失败重试。
- Android `:app:compileDebugJavaWithJavac`：通过，使用本机 JDK 17 与 Android SDK 35。

大文本测试包含 400 篇、每篇约 16,000 字符的不同正文，JSON 为 19,313,841 字节。三个尺寸均验证导入成功、本机索引小于 500,000 字符、刷新恢复及完整 JSON 导出。另覆盖旧正文迁移失败、后台转存失败、正文引用缺失，以及后台提交延迟时不覆盖另一窗口的新快照。

首轮较广回归运行了 222 项，发现图片全选输入问题与重试提示断言需要更新；修复后，对受影响的编辑器、图片、保存快捷键、正文存储和草稿恢复场景重新验证。既有测试中按设备条件跳过的场景不计为通过。

## 当前边界

2026-11-02 发布前复查：修复说明保存失败后重试仍可能保存旧说明的问题，所有成功保存动作会先提交说明草稿。新增项目说明、任务说明的 Ctrl+S 重试及其他保存动作恢复草稿三类场景，三种尺寸共 9 项通过；原有草稿导出恢复 3 项通过。另将同步截图输出移至测试目录，并将格式测试的全文替换改为真实 Ctrl+A 输入，避免固定截图文件锁定与 DOM／编辑器选择范围差异造成误报。

发布验证：单元测试 90 项通过；同步 17 项通过、1 项固定截图写入失败在隔离测试目录复测通过；完整浏览器回归 633 项通过、26 项按设备条件跳过、1 项全文替换测试修正后在三种尺寸复测通过。所有修复完成后，保存快捷键、说明编辑器与笔记编辑器集中回归 105 项全部通过。

本轮为渐进迁移，记录元数据与短正文仍使用 localStorage。发生实际修改时仍传输完整工作区快照和图片；附件独立上传、按记录增量同步、主文件拆分、统一恢复入口及 CI 尚未在本轮实现。

发布前独立审查补充的容量限制：较长正文的历史转存副本与内存去重缓存暂未自动回收，持续编辑长笔记会逐渐增加占用，后续需要在保留其他标签页及恢复能力的前提下增加回收策略。

改动仅在本地工作区，未提交或部署线上，也未生成或安装新版 Android 发布包。Android 文件选择器已通过 Java 编译，实际系统选择器与真机兼容性仍需原生发布前验证。已有未提交的其他功能修改保留。
