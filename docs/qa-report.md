# 拾序交互原型验证

日期：2026-10-18。范围：本地交互原型，非正式四端客户端或云服务验收。

## 结果

- `npm run check`：通过，检查应用模块、数据模块和预览服务的 JavaScript 语法。
- `npm test`：27 / 27 通过，最终运行耗时 41.8 秒。
- 环境：本机 Microsoft Edge、独立测试浏览器上下文；中文区域、Asia/Shanghai 时区。
- 视口：桌面 1440 × 1000、平板 768 × 1024、手机 390 × 844。

## 覆盖流程

每个视口验证以下九项：

1. 创建项目、添加与完成任务、计算进度、修改状态、切换表格，以及刷新后的保留。
2. 笔记创建、正文自动保存、安全的 Markdown 展示、双向项目关联。
3. 筛选、自定义数字属性、按优先级分组；桌面另验证跨列拖动。
4. 快速记录、移入知识库、正文搜索和键盘关闭 / 搜索。
5. 真实下载 JSON 备份，再导入副本，验证原有记录保留和导入关系正确。
6. 主界面无页面级横向溢出、三类页面截图、无运行时异常，以及同步入口诚实呈现未接入状态。
7. 拒绝不支持的备份版本和指向不存在项目的笔记关联。
8. 项目标题编辑后不失焦直接关闭，仍然保存；搜索当前已打开记录时正确关闭搜索框。
9. 同一浏览器两个窗口编辑时，过期窗口不能覆盖另一个窗口的新内容。

## 已知边界

当前数据存储于浏览器 localStorage。尚未实现账号 / 云同步、原生安装包、附件、Service Worker 离线启动或跨设备冲突恢复。未在实体 Android / iOS 设备上验证；手机覆盖为 Edge 的触摸与视口模拟。自动化通过不代表发布级可访问性或性能审计已完成。
