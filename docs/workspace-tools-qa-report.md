# 存储、删除恢复与搜索优化验证

日期：2026-10-21（Asia/Shanghai）。范围：本地源码与隔离测试服务，未部署线上服务。

## 本轮行为

- 主工作区图片内容按 SHA-256 去重后独立保存在 IndexedDB，localStorage 仅保存图片引用。图片事务提交成功后才切换引用；旧格式自动迁移，失败时保留原始存储并停止后续写入。图片缺失时仍保留可导出的文字及其余可用图片，不覆盖原始快照。
- 输入时的同步状态更新不再读取、克隆并校验完整工作区。实际同步、退出账号等边界仍执行完整校验。JSON 导入及同步请求上限由 5 MB 提高到 32 MB；完整导出和同步数据始终包含图片内容。
- 删除项目、任务、笔记前先保存恢复副本；副本失败则不删除。支持立即撤销、本机回收站、恢复和再次确认后永久删除恢复副本。恢复任务保留原位置、完成状态和有效模块；恢复项目保留任务，并重新关联仍存在的笔记。
- 回收站列表按设备、工作区归属隔离；列表只保留记录摘要，实际恢复按 ID 读取对应副本，不一次性保留全部历史图片。恢复前后检查工作区版本及账号绑定，避免覆盖中途变化的内容。
- 搜索支持类型筛选、相关性排序、正文摘要、安全高亮、实际访问历史、方向键和 Enter。任务按自身标题匹配并定位对应事项；笔记结果定位正文匹配。归档内容保留明确标记。
- 修复仅含图片的笔记没有可编辑位置的问题：聚焦所在行后呈现可编辑 Markdown，其他行继续显示图片。

## 已完成的验证

- `npm run check`：通过，覆盖新增模块。
- `npm run test:unit`：72/72 通过，包含删除恢复关系、任务位置、搜索安全高亮，以及大于原 5 MB 上限的真实工作区往返和超限拒绝。
- `npm run test:sync`：16/16 通过，包含图片在第二设备加载、删除后恢复再同步、主工作区图片引用与实验室退出账号的兼容，以及原有账号切换、跨窗口、离线和冲突检查。
- 三种视口的编辑器与新功能专项检查：45/45 通过。后补的图片缺失和大备份导入用例纳入完整回归。
- 完整浏览器回归：405 个用例，首轮 384 通过、20 个按设备条件跳过、1 个失败。失败原因是按项目名搜索时同时列出该项目下所有任务；改为任务按自身标题匹配后，同一用例在平板和手机通过，桌面定向复查连同全部新功能 11/11 通过。当前没有未解决的失败用例。
- 完整回归使用与默认配置相同的单 worker 和三种视口，通过 `.tools/optimization.config.mjs` 在 4194 端口启动隔离服务；桌面复查连接同一隔离服务，单独保存测试结果。
- 已检查手机搜索截图，高亮、摘要、筛选及操作提示在窄屏内可见，注入内容以文字显示。

## 行为边界

- 本轮完成图片分离及输入时的重复处理优化。项目、笔记正文等结构化记录仍保存在 localStorage；同步仍传输完整工作区快照，尚未改为按记录或附件增量传输。
- 回收站本身不跨设备同步；恢复的记录参与正常同步。永久删除移除所选恢复副本，不表示清除所有服务器历史、其他设备备份或共享图片字节。
- 浏览器用例使用独立 Edge 上下文和桌面、平板、手机视口，不代表已验证 iOS Safari 或真实移动设备。
- 测试服务使用独立端口及数据库；没有修改线上账号、数据库或部署状态。32 MB 同步容量需要前后端同时更新后生效。
