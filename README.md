# 拾序 · 项目与个人知识工作台

可在桌面与手机浏览器使用的项目、任务和笔记工作台，已接入自托管账号与多端同步。网页界面、Node.js 同步服务、Docker 与 HTTPS 部署配置均包含在仓库中。

已部署到 [拾序线上工作台](https://8.147.235.91)，使用 Node.js 24、Caddy 与 systemd，支持自动启动和 IP HTTPS 证书续期。Windows x64 桌面安装包位于 `release/desktop/`，使用说明见 [Windows 桌面版](docs/windows-app.md)。Android 安装包位于 `release/android/`，见 [Android 手机应用](docs/android-app.md)；iOS 使用浏览器访问。仓库另保留 Docker 配置作为部署选项。

## 本机运行

使用 **Node.js 24**，在项目目录执行：

```powershell
node server.mjs
```

打开 [拾序工作台](http://127.0.0.1:4173)。运行服务不需要先构建前端，也不依赖在线字体、图标或 CDN。默认仅监听本机 `127.0.0.1:4173`，服务器数据库位于 `.data/shixu.sqlite`。

固定使用同一个地址。协议、主机名和端口共同决定浏览器存储空间：`localhost`、`127.0.0.1` 与线上域名的本机记录互不共享。迁移现有记录时，先在原地址“数据与备份”中导出，再在新地址导入为独立副本。

本机默认允许注册且不要求邀请码，仅供开发体验。公网部署请使用 [VPS 同步部署说明](docs/sync-deployment.md) 中的 HTTPS 与邀请码配置。

部署使用公网 IP `8.147.235.91`，不要求域名。Caddy 为 IP 自动申请及续期受信任的 HTTPS 证书。服务器当前使用原生服务部署；实际目录、维护与备份见 [部署说明](docs/sync-deployment.md)。`scripts/deploy.sh` 适用于另外选择 Docker 的环境。

## 版面与记录

- 主工作区：默认使用精简的项目路线图，顶部保留新建、筛选、排序和归档。路线图可直接勾选任务、逐行添加任务和保存关联笔记，并保留未提交的项目草稿。支持置顶、自定义属性、Markdown 笔记、收藏夹、项目关联与全局搜索。
- [版面实验室](http://127.0.0.1:4173/layouts.html)：今日驾驶舱、时间手账、速记矩阵、项目路线图，支持比较、手机预览、批量添加任务与快速记录。
- [第一轮设计探索](http://127.0.0.1:4173/designs.html)：保留「澄明」「纸间」「夜航」视觉方向；此展示页不接入账号同步。

主工作区按 `Ctrl/⌘ K` 搜索、非编辑状态按 `N` 快速记录。搜索支持项目 / 任务 / 笔记筛选、正文摘要与关键词高亮，按上下方向键选择、Enter 打开；任务结果定位到对应事项，笔记结果选中正文中的匹配文字。空搜索按真实访问记录显示最近打开的内容。实验室按 `N` 定位记录、`/` 定位搜索、`Ctrl/⌘ Enter` 保存。首次打开会生成示例数据，可在登录时决定是否加入账号。

主工作区按 `Ctrl/⌘ S` 保存当前内容，不会打开浏览器的“另存为网页”。笔记和说明保存到本机；新建、编辑或快速记录表单中执行对应的保存操作。空白快速记录框不会新增记录，保存失败时保留已有内容并显示错误。日常编辑仍自动保存。

主工作区非文字编辑状态按 `Ctrl/⌘ Z`，可连续撤销删除项目 / 任务 / 笔记 / 分类、拖动排序、跨分类或模块移动，以及事项的新增、修改和模块删除。当前页面最多保留 50 步；刷新页面或接收远程工作区更新后清空操作历史。输入框和笔记正文内优先撤销文字编辑；删除记录仍可从本机回收站恢复。

在空白页面中使用模板后，可在正文内或非编辑状态按一次 `Ctrl/⌘ Z`，一并恢复套用前的正文、标题、标签和图片附件。套用后继续输入的文字先按编辑器历史撤销，随后再撤销模板。

常用模板卡片右侧可拖动排序，或聚焦拖动手柄后按 `Alt + 方向键` 调整顺序；点击编辑按钮可修改名称、简介和 Markdown 正文，并用“保存模板”或 `Ctrl/⌘ S` 保存。模板修改和排序支持 `Ctrl/⌘ Z`，随工作区备份与同步保留；导入不同版本的同名模板时保留独立副本。

项目首页不再显示视图切换和统计模块，事项下方不重复显示状态文字。保留 `/?layout=board`、`/?layout=table` 和 `/?layout=route` 兼容入口及已有布局偏好。实验室的“应用到我的工作区”只选择布局，不导入预览记录。路线图记录框支持 `Ctrl/⌘ Enter` 保存；草稿按项目保留在当前页面会话，未保存时暂缓同步。

项目详情以待办事项为主，不再展示项目状态、优先级、截止日期、分类、属性面板和任务进度条。项目说明和每条待办的详细说明均可直接编辑 Markdown，支持标题、加粗、斜体、列表、待办、引用、代码、链接和表格；当前行可编辑语法，其他内容实时呈现格式。支持 `Ctrl/⌘ B`、`Ctrl/⌘ I`、正文中的 `Ctrl/⌘ K` 及撤销重做，输入时自动保存。说明会随备份、回收站恢复和多端同步保留，也支持全文搜索。

知识库包含全部笔记，收藏夹展示点亮星星的笔记，两处编辑的是同一份内容；旧收集箱内容自动作为收藏显示，取消收藏仍保留在知识库。分类下展开文章标题，点击直接进入整页编辑器；已选中知识库时再次点击可收起导航。侧栏可调整宽度和收起，搜索与快速记录位于个人空间和工作空间之间。鼠标移到新建加号时，在侧栏右侧选择“新建分类”或“新建页面”，也支持点击、触摸和键盘。

点击“新建页面”立即保存并打开独立编辑器，无需先命名；未填写标题时保存为“未命名页面”，输入框显示“请输入标题”。新页面保留入口的分类、收藏状态和项目关联，返回工作区后仍保留。文档可切换标准宽度与全宽，本机记住偏好并用于新页面。格式工具栏与导出按钮位于同一行，分类、标签和关联项目不在文档中显示，已有数据保留。

页面工具栏可“设为模板／取消模板”。悬停或聚焦新建入口可选择“从模板新建”，也可使用下拉按钮或侧栏新建菜单。模板创建独立页面，复制正文、标签和图片附件，分类、收藏状态与项目关联使用目标位置；模板标记随备份和同步保存。空白正文下方显示会议记录、工作周报、项目复盘、读书笔记、个人规划和自定义模板卡片，“更多模板”打开完整列表；选择卡片应用到当前空白页面并保留已填写的标题，输入正文后隐藏，清空后重新显示。

笔记只保留一个实时编辑区：标题、强调、列表、待办、引用、表格和图片直接呈现，光标所在行可编辑 Markdown 语法。支持格式工具栏、`Ctrl/⌘ B`、`Ctrl/⌘ I`、正文中的 `Ctrl/⌘ K` 以及撤销与重做。图片可选择文件、直接粘贴或拖入，自动压缩后作为笔记附件保存在本机，并随 JSON 备份和工作区同步。导出 `.md` 时内嵌图片数据。原始 HTML 以文本呈现，表格展示经过安全清理。编辑器依赖随页面提供，缓存后可以离线编辑。

顶栏提供浅色与黑夜模式切换，未手动选择时跟随系统；主题、侧栏宽度和文档宽度只保存在当前设备，不随工作区同步。

修改编辑器依赖后运行 `npm run vendor:editor`，生成浏览器使用的 CodeMirror 模块与第三方许可证。

项目页可批量“归档已完成项目”，项目详情可单独归档；项目任务区可批量“归档已完成事项”，编辑任务时也可单独归档。归档内容从日常列表收起，分别在“已归档项目”“已归档事项”中查看和恢复，原有事项状态、模块、整体进度与笔记关联保留，并随备份及同步保存。

侧栏的分类、项目和文章可拖动排序，项目与文章可移到其他分类；首页拖动项目标题旁手柄调整线路顺序，知识卡片拖动左上角笔记图标排序。支持触摸与 Alt + 上下方向键，侧栏记录可用 Alt + 左右切换分类，Esc 取消。手动顺序随备份及同步保存，首页排序菜单可切回其他排序方式。

## 多端同步

点击“账号与多端同步”，注册或登录账号，再明确选择：

1. **同步本机工作区**：将这台设备的记录与账号内容合并；有冲突时比较后决定。
2. **打开账号工作区**：使用账号已有内容，先将本机内容存为恢复备份，不上传这台设备的原有记录。新设备通常选择这一项。

登录本身不会自动上传游客记录。其他设备访问同一个服务域名、登录同一账号并连接对应工作区，即可接收修改。主工作区 `main` 与实验室 `lab` 独立同步；四种实验室版面共用 `lab`，不会混入主工作区。视图偏好留在各设备本机。

修改先保存到浏览器，再自动同步。断网可继续记录，恢复网络后重试；同步状态会显示本机、等待、已同步或冲突。正在输入或有未保存草稿时会延后同步，避免打断编辑。冲突可选择保留双方副本、本机版本或云端版本，处理前会保留恢复备份。

首次联网访问并完成页面缓存后，可在断网时重新打开同一地址；离线启动依赖浏览器支持 Service Worker，线上必须使用 HTTPS，本机回环地址可用于开发。没有首次缓存、缓存被清除或使用不同浏览器时，仍需先联网加载。

## 数据与限制

主工作区的 localStorage 保存记录与图片引用，图片内容单独保存在 IndexedDB，按内容去重；正文编辑不会把图片字节重新写入 localStorage。旧工作区首次打开会先持久保存图片，再切换引用，迁移失败保留原始存储并暂停写入。IndexedDB 同时保存同步基线和恢复备份，Service Worker 缓存页面资源；账号与工作区数据保存在服务器 SQLite 中。登录使用 HttpOnly 会话 Cookie，生产环境启用 Secure 和 SameSite；客户端 JavaScript 不读取会话令牌。当前服务不是端到端加密存储，服务器管理员可以访问数据库内容。

“退出账号”不会清除本机记录或恢复备份。有未同步修改或冲突时，需要先完成同步才能退出；主工作区与实验室会一并检查。共用设备请注意本机数据仍然存在。笔记支持图片附件，尚未提供其他类型附件、密码重置、账号删除界面和 iOS 安装包。

“数据与备份”可导出完整 JSON，并导入为保留现有内容的独立副本。“账号与多端同步”可导出包含当前内容及历史快照的恢复包；恢复包不是普通工作区 JSON，恢复方式见部署文档。清理浏览器数据会删除未上传的内容和本机恢复备份；请同时保留浏览器导出与服务器备份。

主工作区 JSON 导入上限为 32 MB、3,000 个项目、10,000 篇笔记和 30 个自定义字段；同步请求上限也为 32 MB。导出和同步仍携带完整图片内容，当前同步协议仍传输工作区快照。此容量需要前后端同时更新后生效。

主工作区删除项目、任务和笔记前，会先保存本机恢复副本；删除后可立即撤销，也可在“数据与备份 → 本机回收站”恢复或永久删除恢复副本。删除项目仍保留相关笔记，恢复项目时重新关联仍存在的笔记。回收站按设备、工作区与所属账号隔离，未绑定账号的游客记录单独保存；回收站本身不跨设备同步，恢复后的记录正常同步。清理浏览器数据会同时移除本机图片和回收站，完整 JSON 备份包含当前记录的图片，历史删除副本可通过账号面板的恢复包导出。

服务目前按**单实例**运行，不能将 SQLite 数据卷共享给多副本服务。

## 验证

```powershell
npm ci
npm run check
npm run test:unit
npm run test:sync
npm test
```

浏览器测试使用独立浏览器上下文，默认使用本机 Microsoft Edge。`test:unit` 检查同步合并和服务接口，`test:sync` 检查账号、跨设备、离线和冲突流程；`npm test` 运行完整浏览器测试。以上是验证命令，具体结果以当前机器运行输出为准。

产品范围见 [产品说明](docs/product-brief.md)，视觉约定见 [DESIGN.md](DESIGN.md)，已有截图位于 `docs/screenshots/`。

## 依赖

界面采用原生 HTML、CSS 和 JavaScript。同步服务使用 Node.js 24 的内置 SQLite 与加密能力；Docker 镜像不需要安装前端依赖。Pretext 1.0.0 及 MIT 许可证保存在 `public/vendor/pretext/`，Playwright 仅用于开发验证。
